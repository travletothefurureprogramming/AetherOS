# Contributing to AetherOS

Thank you for your interest in contributing to AetherOS. Contributions from the community—whether through bug reports, feature suggestions, documentation improvements, or code contributions—are welcome.

To ensure a smooth collaboration process, please follow the guidelines outlined below.

---

## Code of Conduct

By participating in this project, you agree to maintain a respectful and constructive environment for all contributors. Harassment, offensive language, or disruptive behavior will not be tolerated.

---

## How Can I Contribute?

### 1. Reporting Bugs
If you encounter a bug or unexpected behavior:
* Check the existing issues to see if it has already been reported.
* If not, open a new issue and provide a clear description of the problem, steps to reproduce it, and your environment details (Operating System, Python version, device brands involved).

### 2. Suggesting New Features
If you have an idea for a new feature or improvement (e.g., support for a new device brand):
* Open an issue labeled as an enhancement.
* Explain clearly what the feature should do and why it would be a valuable addition to AetherOS.

### 3. Submitting Code (Pull Requests)
If you want to fix a bug or add a feature yourself:
1. **Fork** the repository and create your feature branch from `main`:

   git checkout -b feature/your-feature-name
